# Engineering portfolio
Open index.html in a browser to preview. No installation, backend or build step required.

## Publish on GitHub Pages
1. Create a new public repository on GitHub (e.g. engineering-portfolio).
2. Upload the CONTENTS of this folder, including the assets folder, to the repository root. Commit the files.
3. Open Settings > Pages. Under Build and deployment choose Deploy from a branch, main, / (root), then Save.
4. Wait for the Pages deployment and open the URL displayed in Settings > Pages.

## Before publishing
Review the project descriptions and confirm university/group coursework sharing permissions. The downloadable PDF contains your student email address; remove or replace the PDF and its links if you do not want this public. No personal phone number, private source code or unverified results are included. The CV is not included because the original contains private contact information. Add a redacted CV later if desired. Add your GitHub profile link when you have public work to showcase.

## Editing
Edit index.html for biography, contact and skills, script.js for case studies, and style.css for appearance. Keep assets in their existing folder. All graphics are local; the hero diagram is decorative, not a real circuit schematic.
